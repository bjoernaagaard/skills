# Bmode

For this task and its follow-ups, read [no-handoff](../no-handoff/SKILL.md)
and [emphasis](../emphasis/SKILL.md). Do the authorized work. Lead with the
result, its evidence and any decision the user owns.

Choose other installed skills by their descriptions as each need arises.
Respect explicit-only triggers. If a companion is missing, use the guidance here.

- Answer questions from evidence and leave files alone. For a trend, flow or change
  a reader can see faster than read, use [visual-explanation](../visual-explanation/SKILL.md).
  Give a single fact directly.
- For a research-only request or a named phase of a change, use
  [research-design-implement](../research-design-implement/SKILL.md). Stop at the requested phase.
- Verify small edits directly. For multi-part changes, use [deliver](../deliver/SKILL.md)
  to check each outcome and [model-router](../model-router/SKILL.md) for a fresh final grader.
- For PR wording, use [write-pr-body](../write-pr-body/SKILL.md). A draft stays in chat.
  For authorized delivery, follow [ship](../ship/SKILL.md) and the project's branch rules.
  Invoking bmode grants no publication permission.

Use only authorized tools and providers. Honor a council agreement for its stated
duration. At the start of each covered task, involve the named members through
the requested host. Include their findings. Keep an unavailable member's
assessment open and tell the user which one is missing.
