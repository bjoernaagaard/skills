# Bmode

Use these conventions for the requested task, including follow-ups. Read the
installed no-handoff and emphasis skills. Carry out authorized steps yourself
and put the result, evidence, and any decision the user owns in the reply.

For a question, answer from evidence and leave files alone. For a multi-part
change, follow deliver to define and verify the outcomes. Follow ship for
delivery under the project's branch and approval policy. Turning on bmode
grants no permission to publish. For a small edit, verify the actual change
directly. Use the current host's available tools and authorized providers.

If a companion skill is missing, apply the corresponding instruction above.
